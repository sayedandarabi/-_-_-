طرح پیاده‌سازی Sync Worker: پایدار و هوشمند

سرویس پس‌زمینه برای مدیریت خودکار انتقال داده‌ها با رعایت محدودیت‌های شبکه

محرک‌ها (Triggers)
اتصال شبکه (NetInfo): شروع خودکار با تغییر وضعیت از آفلاین به آنلاین.
ثبت تراکنش جدید: ماشه فوری پس از تأیید Commit محلی.
سرویس دوره‌ای (Task): بررسی مجدد آیتم‌های شکست خورده هر ۱۵ دقیقه.
فراخوانی دستی: امکان تلاش مجدد توسط کاربر در داشبورد.
استراتژی اجرا (Strategy)
پردازش دسته‌ای (Batching): ارسال حداکثر ۲۰ تراکنش در هر درخواست برای بهینه‌سازی پهنای باند.
صبر نمایی (Exponential Backoff): افزایش فاصله زمانی بین تلاش‌های مجدد در صورت خطای شبکه (۱، ۵، ۱۵، ۶۰ دقیقه).
وضعیت ماندگار: ثبت تعداد تلاش‌ها و آخرین پیام خطا در صف محلی برای عیب‌یابی.
// Sync Logic Pattern
while (hasPendingItems && !isOffline) {
  const batch = outbox.take(20);
  const result = await api.sync(batch);
  updateLocalState(result);
}
